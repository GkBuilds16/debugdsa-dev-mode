# Testing

Verified for this phase: 20 backend tests pass, 1 frontend component test passes, the production build succeeds, and `npm audit --audit-level=moderate` reports zero vulnerabilities. Run backend tests from the root with `npm test`, frontend component tests with `npm run test -w frontend`, and compile the frontend with `npm run build`. Backend API tests use mocked Mongoose model calls and an ephemeral HTTP server. Post Codebase service tests cover validation, unsafe ZIP entries, storage-key isolation, and GitHub URL policy; the creator dashboard test covers fetching and filtering. These tests do not constitute MongoDB integration, database concurrency, browser end-to-end verification, or a complete UI control audit.

Remaining high-priority tests: published snapshot lifecycle against MongoDB, full candidate endpoint ownership/confidentiality coverage, concurrent battle capacity/duplicate registration with MongoDB, ZIP upload route integration, editor form/autosave/publish interactions, and browser end-to-end flows. The current environment has no verified MongoDB service, so database integration tests were not run.
